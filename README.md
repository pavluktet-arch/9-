# 🚀 Mini REST API on Pure Node.js

Цей проект є навчальним модулем, що демонструє створення повноцінного **REST API** без використання сторонніх бібліотек чи фреймворків (як-от Express чи Fastify)[cite: 1, 4]. Проект реалізує всі основні операції **CRUD** (Create, Read, Update, Delete) з використанням вбудованих модулів `http`, `fs` та `path`[cite: 1, 2, 3, 4, 5].

## 📋 Функціональність

Проект розділений на 5 модулів, кожен з яких відповідає за певне завдання:

1. **List Items (`rest_list.js`)**: Повертає повний список об'єктів із файлу `data.json` зі статусом `200`[cite: 4].
2. **Get Item by ID (`rest_get.js`)**: Шукає елемент за його ID в URL. Повертає дані об'єкта або `404`, якщо його не існує[cite: 2].
3. **Create Item (`rest_create.js`)**: Приймає `POST` запит із JSON-тілом, додає новий елемент у базу та повертає статус `201 Created`[cite: 1].
4. **Update Item (`rest_update.js`)**: Оновлює існуючий об'єкт за вказаним ID через метод `PUT`[cite: 5].
5. **Delete Item (`rest_delete.js`)**: Видаляє об'єкт із файлу за його ID через метод `DELETE`[cite: 3].

## 📂 Структура проекту

* **rest_list.js** — Отримання всього списку[cite: 4].
* **rest_get.js** — Отримання одного елемента[cite: 2].
* **rest_create.js** — Створення нового запису[cite: 1].
* **rest_update.js** — Редагування даних[cite: 5].
* **rest_delete.js** — Видалення даних[cite: 3].
* **data.json** — Локальне сховище даних у форматі масиву.
